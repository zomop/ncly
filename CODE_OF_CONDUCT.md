# Code of Conduct

## Our commitment

NCLY is a technical project. Participation is open to anyone regardless of
experience level, background, identity or affiliation. We are committed to a
harassment-free experience for everyone.

## Expected behaviour

- **Discuss the code, not the person.** Critique ideas, algorithms and evidence.
- **Assume competence.** A wrong number is usually a subtle bug, not carelessness.
- **Be precise.** "This returns 4.999999999 instead of 5" is more useful than
  "this is broken".
- **Credit contributions.** If someone found the bug you are fixing, say so.

## Unacceptable behaviour

- Harassment, insults, or discriminatory comments of any kind.
- Personal or political attacks.
- Publishing someone's private information without permission.
- Sustained disruption of technical discussion.
- Dismissing a bug report without evidence.

## Scope

This applies to issues, pull requests, commit messages, code comments and any
other project space.

## Enforcement

Report concerns privately to the maintainers through the repository's
[security advisory](https://github.com/zomop/ncly/security/advisories/new) form or
by opening an issue asking for a private channel. Reports are reviewed
confidentially. Maintainers may remove comments, close issues, or block accounts
that violate this document.
